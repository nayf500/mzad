# مزاد اللوحات

صفحة واحدة عربية RTL لعرض وإدارة مزاد لوحة، مع لوحة إدارة محلية.

## التشغيل
افتح `index.html` مباشرة، أو ارفع الملفات إلى GitHub Pages.

## دخول الإدارة
كلمة المرور الافتراضية: `1234`

يمكن تغييرها من داخل لوحة الإدارة.

## مهم
هذه النسخة تعمل بدون خادم باستخدام `localStorage`. لذلك هي مناسبة كنموذج/أداة خاصة على جهاز واحد، لكنها **ليست نظامًا آمنًا حقيقيًا لإدارة مزاد عام**. كلمة المرور وبيانات المزاد موجودة في متصفح الجهاز.

إذا أردت لاحقًا مزادًا عامًا متعدد الأجهزة مع بيانات مشتركة وحماية حقيقية، نحتاج Backend وقاعدة بيانات ومصادقة على الخادم.
