# مزاد اللوحات السعودية

نسخة مطورة بواجهة لوحة سعودية بتقسيم الرقم والحروف وKSA، مع اختيار شعار من عدة خيارات أو رفع شعار مخصص.

## تشغيل
ارفع الملفات الأربعة إلى GitHub ثم فعّل GitHub Pages.

## الدخول
كلمة مرور الإدارة الافتراضية: `1234`

## ملاحظة
هذه النسخة محلية باستخدام localStorage. كلمة المرور وبيانات المزاد محفوظة في متصفح الجهاز وليست نظام مصادقة خادم حقيقي. للاستخدام العام متعدد الأجهزة يلزم Backend وقاعدة بيانات.
